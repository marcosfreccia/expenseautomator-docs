Getting started

Complete account setup ​

The setup checklist turns transaction history into a useful starting point for your account.

Your progress is saved, so you can return to unfinished steps after signing in. The available steps depend on your plan and the financial activity imported into your account.

Follow the checklist ​

Confirm plan and billing

Review the plan associated with your account and complete any required subscription step.

Import transaction files

Add up to ten original CSV files at a time. Each file can be up to 5 MB. Supported bank formats are detected automatically.

Review the financial analysis

Use the imported activity to review the initial picture of income, spending, and financial health.

Shape proposed budgets

Review the starting budgets suggested from your activity and adjust them to match your priorities.

Confirm recurring activity

Check transactions identified as recurring so future views can represent regular commitments more accurately.

Create a first goal

Add a target you want to track, then review the setup summary and finish onboarding.

While files are processing ​

Uploaded files move through format detection, transaction import, and categorisation. Keep the setup page open while processing continues. If one file fails, the page shows its error and provides a retry action.

Duplicate transactions are skipped. A completed file reports its detected bank, the number imported, and the number of duplicates found.

After setup ​

You will arrive at the main application with access to your dashboard and the features included in your plan. Start by checking the imported totals and uncategorised transactions before relying on reports or budget comparisons.
