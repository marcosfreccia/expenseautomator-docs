Features

Categories ​

Categories organise transactions for dashboards, reports, and spending analysis. Use them for areas such as groceries, dining, utilities, salary, or transfers.

Premium feature

Creating, editing, and assigning custom categories requires Premium. Household members also need permission to edit shared data.

Manage categories ​

Open Setup → Categories. Each category card shows its name, icon, colour, group, and any reporting options.

To create a category:

  1. Select Add category.
  2. Enter a name.
  3. Optionally choose a group.
  4. Select a colour and icon.
  5. Configure any reporting options.
  6. Select Save category.

Use the pencil button on a category card to edit it.

Names and groups ​

  • Names must be unique within the same group.
  • Uncategorized is reserved and cannot be used.
  • A category can belong to one top-level group.
  • Groups cannot be nested.

For example, create Food as a group and add Groceries, Dining, and Takeaway beneath it.

Assign a category ​

Open a transaction, choose a value from Category, and save the transaction. You can also filter the transaction list by category.

Category and budget assignments

A transaction can have either a custom category or a budget assignment. Assigning a category removes its existing budget assignment.

For repeated transactions, use a rule to assign the category automatically.

Reporting options ​

Treat as transfer ​

Enable Treat as transfer for money moved between accounts you own. These transactions remain visible but are excluded from income and expense totals.

Examples include transfers to savings or payments between your own accounts.

Ignore in reports ​

Enable Ignore in reports to keep transactions visible while excluding them from dashboard totals, charts, analytics, and reports.

Changing either option affects transactions already assigned to the category and may change existing totals.

Current limitations ​

  • Categories cannot currently be deleted from the Categories page.
  • Groups support one level only.
  • Free accounts can preview categories but cannot assign or manage them.
